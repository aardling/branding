Installation

Published to GitHub Packages, not the public npm registry.

@aardling:registry=https://npm.pkg.github.com
//npm.pkg.github.com/:_authToken=${GITHUB_TOKEN}

  1. Commit this .npmrc in the consuming project. It names the registry, not the secret.
  2. The token is a classic personal access token scoped to read:packages and repo.

npm install @aardling/brand-aardling

Usage

@import "@aardling/brand-aardling/assets/fonts/fonts.css";
@import "@aardling/brand-aardling/tokens/tokens.css";

  1. Tokens: CSS custom properties, or data in tokens/tokens.json.
  2. Logos, icons, images and fonts: assets/.
  3. Agents: copy or symlink skills/aardling-brand into .claude/skills/.
