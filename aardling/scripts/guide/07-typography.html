Typography

Display

Voyage

--font-display: Voyage, Georgia, "Times New Roman", serif. Static Regular only: no italic, no variable axis.

Body

General Sans

--font-body: "General Sans", "Helvetica Neue", Helvetica, Arial, sans-serif. Variable: one file per style, weight 200 to 700.

Files

  1. Both faces are self-hosted woff2 files in the package.
  2. Never load a face from Google Fonts, Fontshare or any other third-party host.

Letter-spacing

  1. None, at any size, in either face.
  2. Exception: uppercase labels take 0.12em to 0.14em.

Wrapping

  1. Headings, taglines, pull quotes, buttons, captions: balanced.
  2. Body copy: no orphans.
  3. Protected terms never break. See page {{FOLIO:layout}}.

Typography Weights

Weights

200 ExtralightVery large display settings only
300 LightLarge introductory paragraphs
400 RegularBody copy, buttons, captions — the default
500 MediumHeadings, everywhere
600 SemiboldEmphasis in running text, table headers
700 BoldRare — only where 600 fails to separate
  1. Headings are 500. Use --font-weight-heading, not the literal.
  2. Voyage is Regular only.

Italics

400 Regular italicThe title of a work
500 Medium italicA term being introduced
600 Semibold italicA genuine aside
  1. Italics exist at every weight.
  2. Never use italics for emphasis. Use 600.

Typography Which face, where

Which face, where

  1. Use Voyage once per page, on one short title — normally the h1.
  2. A second Voyage setting on a page needs a reason.
  3. Keep the Voyage title to one line of a few words.
  4. Never set Voyage below 24px. A smaller title is General Sans.
  5. Never set Voyage on a gradient. A heading on a gradient is General Sans at the heading weight. See page {{FOLIO:imagery}}.
  6. Set everything else in General Sans: h2, h3, card titles, call-to-action headings, pull quotes, form section labels, table captions, sidebar headers.
