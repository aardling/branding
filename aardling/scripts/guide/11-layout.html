  1. In markup, wrap the whole term in one span with white-space: nowrap.
  2. In plain text, use U+00A0 between the words and U+2011 for the hyphen.
  3. Prefer the span wherever markup exists. U+2011 is missing from many fonts, Voyage included.
  4. If a term does not fit the line, change the line: reflow, widen the column, or set the type smaller.

Text on images

  1. Never text on a photograph or illustration, even with a scrim, blur or gradient overlay.
  2. Alternatives, in order: text beside the image; text on an adjacent solid panel; the image reduced to an accent.
  3. The website's default hero and several original guide mockups break this. They change.
  4. Only exception: a mark or a single heading on a gradient. See page {{FOLIO:imagery}}.
