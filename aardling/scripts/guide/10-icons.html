Icons guidelines/icons.md

Sizes

--icon-sm16pxInline with small text; dense controls.
--icon-md20pxInline with body copy. The default.
--icon-lg24pxButtons, navigation items, list bullets.
  1. No size above 24px.
  2. Set height and leave width: auto. Not every mark is square.
  3. The set is drawn on one 16×16 grid at stroke 1.25.
  4. download carries its own 14×14 box. At the same pixel height it looks lighter than its neighbours: start from the sizes above, place it beside its text and adjust by eye.

Icons Labels and metaphors

Not allowed

  1. An icon is never the only label. An icon-only control needs an accessible name.
  2. If the meaning is not obvious to someone outside our field, add visible text as well.
  3. A tooltip does not replace a label: a thumb cannot hover.
  4. Only these marks may stand alone on a control. Everything else takes a visible label.

  1. No emoji as icons. An emoji does not take currentColor, does not match the stroke weight, and renders differently per platform. Where the set has no mark, use text.
  2. No cliché metaphors. Draw functional marks only — an action or a thing: back, download, search, a file, a clock.
  3. Never a picture standing in for an abstract concept: a lightbulb for an idea, a rocket for a launch, a gear for engineering, a target for a goal, a handshake for a partnership, a puzzle piece for fit, a compass for strategy. The concept stays in the words.
